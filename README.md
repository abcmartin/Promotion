# CD44_Manus

Dieses Repository bündelt:
- Build-/Manubot-Struktur aus: https://github.com/abcmartin/rootstock.git
- Manuskriptquellen aus: https://github.com/abcmartin/manuscript/tree/main/manuscript
- Editor-Komponente aus: https://github.com/abcmartin/manubot-ai-editor.git

## Voraussetzungen
- git
- Python oder Node.js (abhängig vom Editor)
- optional: Docker

## Schnellstart
1. Repository klonen.
2. `make html` oder entsprechendes Manubot-Kommando ausführen.
3. Editor starten: siehe `editor/README.md`.

## CI
Die CI-Pipeline baut das Manuskript und lädt Artefakte hoch.
