# Manuskript-Editor

Dieses Verzeichnis ist für die Integration von https://github.com/abcmartin/manubot-ai-editor.git vorgesehen.
Start (Beispiel):

```bash
cd editor
npm install
npm run dev
```

Der Editor soll auf die Inhalte im Verzeichnis content/ zugreifen können.
